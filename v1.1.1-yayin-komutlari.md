# v1.1.1 Hotfix — Yayın Komutları (2 Haziran 2026)

Bu dosya, v1.1.1 sürümünü çıkarmak için Mac terminal'inde yapman gereken adımları içerir. Her adımı **kopyala → yapıştır → Enter** ile çalıştır.

## ÖNCE: Terminal'i Aç

Spotlight'tan "Terminal" yazıp aç. Aşağıdaki **ilk komutu** yapıştır — proje klasörüne girer ve Node 20'yi aktive eder:

```bash
cd ~/istanbul-rehber && export PATH="/opt/homebrew/opt/node@20/bin:$PATH" && node --version
```

Çıktıda `v20.x.x` görürsen devam et. `v24.x` görürsen Node 20 path yanlış, bana söyle.

## ADIM 2: Build Başlat (~25-35 dakika)

Bu komut hem iOS hem Android için production build başlatır. EAS sunucusunda çalışır, Mac'in yormaz. Sadece komutu çalıştır ve git başına git, kahveni iç.

```bash
eas build --platform all --profile production --non-interactive
```

İlk kez sorabilir:
- "Auto-increment build number?" → **Y** (Enter)
- "Generate new keystore?" gibi sorular → Mevcut credentials kullanılır, sorun olmaz

**İzleme:** Komut sonunda iki link verir (iOS ve Android için). Browser'da aç, build progress görebilirsin.

Build bittiğinde Terminal'de iki yeşil "Build finished" satırı görürsün ve `.ipa` + `.aab` dosya bağlantıları verir.

## ADIM 3: App Store + Play Store'a Yolla

Build bitince hemen submit et. İki ayrı komut, paralel çalıştırabilirsin (iki ayrı terminal sekmesi):

```bash
# iOS — App Store Connect'e gonder
eas submit --platform ios --latest
```

```bash
# Android — Google Play Console'a gonder
eas submit --platform android --latest
```

Submit ~2-3 dakika sürer. Sonunda her ikisi de "Successfully submitted" döndürmeli.

## ADIM 4: Mağaza Review İste

### Apple App Store
1. App Store Connect aç: https://appstoreconnect.apple.com
2. Pusula İstanbul → TestFlight + App Store sekmesi
3. v1.1.1 buildNumber 41 görmelisin (yüklendi mi kontrol et)
4. **Submit for Review** → Manual Release seç
5. Apple'a not bırak (kopyala):

```
Hotfix for v1.1.0:
1. Fixed Android notification channel sound — push notifications arriving silently on Android due to channel sound parameter misinterpretation.
2. Restored UI for deleting general announcements (admin/moderator feature missing from v1.1.0 build).
No new features, no permission changes.
```

### Google Play Console
1. Play Console aç: https://play.google.com/console
2. Pusula İstanbul → Production → Releases
3. versionCode 42 yüklendi mi kontrol et
4. **Create new release** → Bundle olarak v1.1.1 ekle
5. Release notes (TR + EN) yapıştır:

**Türkçe:**
```
Bazı Android cihazlarda push bildirimlerinin sessiz gelmesi sorunu giderildi. Yetkili kullanıcıların genel duyuruları silebilmesi için "Sil" butonu eklendi. Genel kararlılık iyileştirmeleri.
```

**English:**
```
Fixed silent push notification issue on some Android devices. Added "Delete" button for authorized users to remove general announcements. General stability improvements.
```

6. **Save** → **Review release** → **Start rollout to Production**
