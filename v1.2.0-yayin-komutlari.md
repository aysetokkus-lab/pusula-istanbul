# v1.2.0 — Yayın Komutları (4 Eylül 2026)

Büyük sürüm: tamamen ücretsiz model, Kobalt & Menekşe tasarım, Ajanda + Masraf Pusulası, Rehber Aranıyor ilanları, DM, sohbet tepki/yanıt/görsel.
Native değişiklik var (react-native-purchases çıktı; expo-image-picker, expo-mail-composer, expo-sharing, expo-file-system girdi; yeni ikon/splash) → **mağaza build'i şart, OTA yetmez.**

Sürüm: app.json `1.1.1 → 1.2.0`, iOS buildNumber `42 → 43`, Android versionCode `43 → 44` (EAS `autoIncrement` bir tık daha artırabilir — sorun değil, mağazada görünen numarayı not et).

Her adımı **kopyala → yapıştır → Enter**.

---

## ADIM 0: Terminal + Node 20

```bash
cd ~/istanbul-rehber && export PATH="/opt/homebrew/opt/node@20/bin:$PATH" && node --version && git status -sb | head -1
```

`v20.x` görmelisin. `git status` satırı `ahead N` diyorsa push edilmemiş commit var → Adım 1'e geç.

---

## ADIM 1: Push (dünkü + bugünkü commit'ler)

```bash
git push origin main
```

Beklenen: `To github.com:aysetokkus-lab/pusula-istanbul.git` + `main -> main`. Bu push ile `docs/varliklar/` GitHub Pages'e çıkar → PDF/Word/Excel çıktılarında logo ve Poppins görünür (5–10 dk sürebilir; kontrol: https://pusulaistanbul.app/varliklar/logo-kobalt-192.png).

---

## ADIM 2: Build başlat (~25–35 dk, EAS sunucusunda)

```bash
eas build --platform all --profile production --non-interactive
```

Komut iki link verir (iOS + Android). Tarayıcıda açıp ilerlemeyi izleyebilirsin. Bittiğinde iki yeşil "Build finished".

Hata alırsan (özellikle iOS credentials / Android keystore) çıktının son 30 satırını bana yapıştır.

---

## ADIM 3: Mağazalara gönder (build bitince, iki ayrı sekmede paralel olabilir)

```bash
eas submit --platform ios --latest
```

```bash
eas submit --platform android --latest
```

Android `releaseStatus: draft` → Play Console'da taslak olarak durur, sen yayınlarsın. iOS → App Store Connect'e yüklenir, TestFlight'ta görünür.

## ADIM 5: Mağaza review

### App Store Connect — https://appstoreconnect.apple.com
1. Pusula İstanbul → App Store sekmesi → **+ sürüm 1.2.0**
2. Build 43'ü seç
3. **Açıklama metnini güncelle** — eski metinde "ücretli uygulama / 7 gün deneme / 99 TL – 699 TL abonelik" ifadeleri var, HEPSİ ÇIKACAK (aşağıdaki yeni metin)
4. In-App Purchases bölümünde abonelik seçili kalmasın
5. Yeni izin yok (kamera/galeri zaten 1.1.x'te vardı) ama açıklamaları değişti — sorun değil
6. Submit for Review → **Manual Release**
7. Review notu:

```
Major update 1.2.0:
- The app is now completely free. All in-app subscriptions (RevenueCat) have been removed; no paywall remains.
- New visual design.
- New "Agenda + Expense Sheet" feature: guides log their tours and expenses, attach receipt photos, and export PDF/Word/Excel via the device's own mail/share sheet (expo-mail-composer, expo-sharing). Camera/photo permissions are used for receipts and chat images.
- Job board ("Guide wanted"), private messaging, chat reactions/replies/images.
No new permissions beyond camera and photo library, both already declared in 1.1.x.
```

### Google Play Console — https://play.google.com/console
1. Pusula İstanbul → Production → Releases → taslak release (versionCode 44)
2. **Mağaza kaydı → Ana mağaza kaydı → Açıklama**: abonelik ifadelerini kaldır (yeni metin aşağıda)
3. **Para kazanma → Ürünler → Abonelikler**: satıştan kaldırıldı (3 Eyl) — kontrol et
4. Release notes yapıştır → Review release → **Start rollout** (istersen önce %20 kademeli)
