# Dışa aktarma varlıkları

`masraf-disa-aktar` Edge Function'ı bu klasörü `https://pusulaistanbul.app/varliklar/` üzerinden çalışma anında okur
(izolasyon ömrünce önbellek). Fontlar Poppins'in Latin + Türkçe + € ₺ alt kümesidir (OFL, pyftsubset).
Logo yoksa çıktılar logosuz üretilir; font yoksa google/fonts deposundan tam TTF çekilir.
